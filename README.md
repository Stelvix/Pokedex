### Notifications Discord – GitHub Webhook

Ce webhook permet de synchroniser les événements importants du dépôt GitHub avec un salon Discord dédié.

**Événements surveillés :**
- **Push** : notification lors de l'envoi de nouveaux commits.
- **Pull Request** : notification lors de la création ou de la modification d'une demande de fusion.
- **Issues** : notification lors de la création ou de la modification d'une issue.
- **Star** : notification lorsqu'un utilisateur ajoute une étoile au dépôt.

**Objectif :** faciliter le suivi de l'activité du projet et permettre à toute l'équipe de rester informée des changements sans devoir consulter GitHub constamment.

**Intégration :** GitHub Webhooks → Discord.
